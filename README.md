# نظام إدارة المنتجات (Product Management System - CRUDS)

تطبيق ويب تفاعلي وبسيط لإدارة المنتجات وحساب تكاليفها بشكل لحظي. يتيح للمستخدم إكانية إضافة، عرض، تعديل، وحذف المنتجات بسهولة، مع دعم خاصية البحث السريع والتخزين المحلي للبيانات.

---

## 🌟 المميزات الرئيسية (Key Features)

* **عمليات CRUDS الكاملة:** (إنشاء Create - عرض Read - تعديل Update - حذف Delete - بحث Search).
* **حاسبة أرباح وتكاليف لحظية:** حساب إجمالي السعر تلقائيًا بناءً على (السعر الأصلي، الضرائب، الإعلانات، والخصم).
* **إضافة متعددة:** إكانية إضافة كميات محددة من نفس المنتج بضغطة زر واحدة (Count).
* **بحث متقدم:** إكانية البحث عن المنتجات عن طريق **العنوان (Title)** أو **الفئة (Category)**.
* **حفظ البيانات (Data Persistence):** الاعتماد على الـ `LocalStorage` لحفظ البيانات حتى لا تضيع عند إغلاق الصفحة.
* **الوضع الليلي والنهاري (Dark/Light Mode):** تبديل سلس بين الثيم المظلم والمضيء مع تعديل الألوان تلقائيًا.
* **تصميم متجاوب (Responsive Design):** التكيف مع جميع الشاشات (الموبايل، التابلت، والشاشات الكبيرة).

---

## 🛠️ التقنيات المستخدمة (Tech Stack)

* **HTML5:** لبناء هيكلية الصفحة والجدول.
* **CSS3:** للتنسيق وإضافة الأنيميشن وخصائص الـ Responsive Design.
* **JavaScript (Vanilla JS):** لبناء المنطق (Logic)، والتعامل مع DOM، وحساب التكاليف، وإدارة الـ LocalStorage.
* **FontAwesome:** لاستخدام الأيقونات التفاعلية.
